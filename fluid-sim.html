Fluid Simulation

[Made in 2025]

This is a C implementation of a liquid simulation, inspired by this article (light mode site, be cautious): 2D Liquid Simulator with Cellular Automaton in Unity.

This project simulates liquid behavior using simple rules applied to a grid. I created it to deepen my understanding of the C language and to begin developing simulations like this in C.

You can access the demo compiled to WASM to run in your browser here: Fluid Simulation Demo
